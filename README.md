# 🎬 Movie Popularity & Rating Data Analysis

## Overview

This project performs an end-to-end Exploratory Data Analysis (EDA) on a dataset of 10,000 movies. It demonstrates foundational Data Science skills using Python, including heavy data manipulation, missing value imputation, outlier detection, mathematical operations, and data visualization.

## Objectives

1. **Data Cleaning:** Handle missing values, remove duplicates, standardise text, and detect outliers using the Interquartile Range (IQR) method.
2. **Data Manipulation (Pandas):** Extract datetime features, group data, merge DataFrames, and aggregate statistics.
3. **Numerical Operations (NumPy):** Perform statistical calculations, array slicing, reshaping, and mathematical transformations.
4. **Exploratory Data Analysis (EDA):** Visualize distributions, trends over time, and correlations using Matplotlib and Seaborn.

## Dataset

* **Source:** TMDB (The Movie Database) subset.
* **Size:** 10,000 rows, 8 columns.
* **Key Features:** `title`, `release_date`, `popularity`, `vote_average`, `vote_count`.

## Tech Stack

* **Python** * **Pandas** (Data manipulation)
* **NumPy** (Numerical computing)
* **Matplotlib & Seaborn** (Data Visualization)

## How to Run

1. Clone this repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the script: `python movie_analysis.py`
